# UR5 model provenance

[简体中文](README.zh-CN.md) · English

`ur5.xml` is a project MJCF model based on the original UR5 kinematic and physical
parameters in Universal Robots' `Universal_Robots_ROS2_Description` repository.
The parameters were checked against its `config/ur5/default_kinematics.yaml`,
`joint_limits.yaml`, `physical_parameters.yaml`, `visual_parameters.yaml`, and
`urdf/ur_macro.xacro`. The kinematic frames match the official description at
zero and nonzero joint configurations. The six link collision meshes are from
`config/ur5` in that repository and are used as both visible and contact meshes.

UR5 source commit: `89bbe795f38a7ab00fb66fe8831dfff79dc99edf` (BSD-3-Clause;
see [`UR_DESCRIPTION_LICENSE`](UR_DESCRIPTION_LICENSE)).

The initially reviewed `parhamkebria/UR5` candidate was commit
`c215f44ef8f11554ae584dfca366b6ee722e8f36` (Apache-2.0). Its body offsets,
joint frames, and end-effector site did not match the current official UR5
description, so its model and meshes are not redistributed here.

The attached 2F-85 model is assembled from the unmodified MuJoCo Menagerie model
and its assets. The gripper's `base_mount` is attached at the official UR `tool0`
frame (the URDF `tool0` transform has identity orientation relative to
`wrist_3_link` and zero translation). The `tcp` site aliases the upstream
`pinch` site at the center between the fingers. MuJoCo Menagerie commit:
`c96a32d28fb5da84da38c1da4d749e7a13212855` (BSD-2-Clause; see
[`2F-85 license`](../robotiq_2f85/LICENSE)). `ur5_2f85.xml` is reproducibly
generated by `tools/assemble_model.py`.
